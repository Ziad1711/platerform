```sql
  join pg_class c on c.oid = t.tgrelid
```

```sql

   set kill_switch = true,
       requested_mode = 'legacy'
```

Effet attendu : prochain poll ≤ 5 s, expiration sûre ≤ 15 s, journal de
télémétrie conservé.

activés : arrêt worker/réveil et suppression des triggers d'invalidation ;
