## 1. Verrou serveur réel (`lib/dashboard/kpi-reader-flag.ts`)

| Condition | Effet |
|---|---|
| `KPI_READER_V5` absent ou ≠ `'1'` | `kpiReaderV5Enabled()` = `false` → rollout désactivé |
| Projet Supabase = `attvfeoqgbxsnnsllatt` (Production) | exige `KPI_READER_V5_PRODUCTION_ACK` **égal exactement** à ce ref |
| Projet = `goqedvcdmgtejtyrawsp` (Test) | autorisé si `KPI_READER_V5=1` |
| Tout autre projet, URL absente ou invalide | `false` (défaut sûr) |

Le rendu serveur reste `legacy` (`kpiReaderServerMode()` /
`kpiReaderV5Source()`), quel que soit l'état des variables : aucun premier
rendu ne peut afficher du V5.

**Conséquence :** le mode effectif est décidé par la configuration en base
(`rpc_dashboard_kpi_rollout`), pas par la variable. La variable n'autorise que
la possibilité d'interroger cette configuration.

## 2. Configuration OFF

État attendu en base (`dashboard_kpi_rollout_config`, ligne `id = 1`) :

- `kill_switch = true`
- `requested_mode = 'legacy'`
- `readiness_rbl4 = false`, `readiness_tzdata = false`, `readiness_backend = false`
- `shadow_sample_pct = 10`
- `dashboard_kpi_rollout_cohorts` : 0 ligne
- `dashboard_kpi_rollout_events` : 0 ligne

Tant que les trois readiness ne sont pas vraies, la résolution serveur renvoie
`legacy` même si `requested_mode` valait `shadow` ou `v5`.

Variables Vercel attendues en Production pour cette livraison :

- `KPI_READER_V5` = `0` (ou absente)
- `KPI_READER_V5_PRODUCTION_ACK` = absente

Aucune cohorte ne doit être créée dans cette étape. Les preuves P7.4 (Test)
ne valent pas autorisation Production.

## 3. Retour legacy (comportement et délais)

| Déclencheur | Délai attendu | Source |
|---|---|---|
| `kill_switch = true` | poll ≤ 5 s | `KPI_ROLLOUT_POLL_MS` |
| Configuration non rafraîchie | ≤ 15 s | `KPI_ROLLOUT_TTL_MS` |
| Réponse réseau tardive / hors ordre | rejetée | garde `acceptsRolloutEntry` |
| Erreur réseau à froid | `legacy` immédiat, `stale = true` | `resolveKpiRolloutMode` |

Au passage en legacy, les caches KPI V5 sont supprimés
(`CACHE_PREFIXES`) : aucune valeur V5 ne doit subsister dans l'interface.

Procédure immédiate, sans redéploiement (autorisation distincte requise) :

```sql
update public.dashboard_kpi_rollout_config
   set kill_switch = true, requested_mode = 'legacy'
 where id = 1;
delete from public.dashboard_kpi_rollout_cohorts;
```

Le journal de télémétrie est conservé pour diagnostic.
