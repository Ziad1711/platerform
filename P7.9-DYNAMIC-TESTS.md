## 9. Limites

1. Concurrence réellement parallèle (deux sessions, verrou tenu par une autre
   transaction) non testée : une seule session disponible.
2. Dimension agent non couverte (F7) ; devise multiple et sélection
   inter-boutiques non rejouées dans cette campagne.
3. Les mesures de coût sont un micro-benchmark (200 mises à jour sur une
   commande), pas une mesure de charge ; le coût des agrégats n'est pas inclus.
4. Les transactions annulées ne prouvent pas le comportement du worker cron réel :
   aucun événement de test n'a été visible hors transaction.
