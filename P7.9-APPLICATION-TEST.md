## 6. Écarts et limites

1. Le trigger dédié porte le total `trg_kpi_%` de **6 à 7** (le paquet P7.1
   annonçait 5 : la base de Test en comptait déjà 6 avec `trg_kpi_wakeup`
   désactivé). Documentation à actualiser, aucun objet supprimé.
2. `service_role` **sans JWT** ne peut pas utiliser la surcharge : le contrôle
   d'accès interne préexistant (`dashboard_legacy_access`, `auth.uid()` nul)
   renvoie `DASHBOARD_NO_ACCESS`. La surcharge est donc inutilisable en pratique
   tant qu'elle n'est pas corrigée : restriction conforme à la décision, mais
   plus stricte que « service_role conservé ».
3. Aucun **marketer** ni **membre inactif** n'existe sur jisra-test : ces deux
   branches sont **NOT COVERED** en réel (même chemin de code que viewer / none).
4. P7.7 et P7.8 n'apparaissent pas dans l'historique des migrations de Test ;
   seule la ligne `20261020120000_p79_p0_closure_bundle` a été ajoutée pour ce
   lot (quatre fichiers en une transaction).
5. Les tests métier avec données synthétiques (`business_cases.sql`) restent
   **non exécutés** : autorisation séparée requise.
